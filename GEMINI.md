# LookupLab

Use LookupLab for phone carrier/line-type, email domain, IP network and email-DNS checks requested by the user. Check only inputs the user supplies or authorizes. These tools debit the connected LookupLab account's existing credits. Phone checks cost 1 to 3 credits, caller name adds 2, other checks cost 1. Do not launch unsolicited bulk checks.

Carrier information does not verify identity or consent to contact. Email checks do not guarantee delivery or mailbox ownership. IP location is approximate and privacy fields may be unavailable. Report unavailable fields as unknown. Do not ask users to paste API keys into a conversation; use the extension's secure API-key setting. Never include a credential in a tool argument, URL, log or generated file.
