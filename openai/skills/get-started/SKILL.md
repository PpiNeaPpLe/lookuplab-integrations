---
name: get-started
description: Connect an existing LookupLab account and explain the available phone, email, IP and DNS checks.
---

Connect through the platform's OAuth connection UI. Never request an API key in the conversation. LookupLab authenticates the account on its own HTTPS consent page.

Explain the available checks briefly and ask which supplied number, address or domain the user wants checked. Run only the requested checks. Successful tools consume the account's existing credits: phone checks 1 to 3, optional caller name adds 2, other checks 1. Never start unsolicited bulk work. Return actual results and acknowledge missing data. A carrier listing is not proof of identity or consent, an email domain check is not proof of mailbox ownership, and IP geolocation is approximate.

If authorization fails, ask the user to reconnect through the platform. If the balance is insufficient, state that the requested check cannot be completed with the current balance. Do not offer purchases, subscriptions or upgrades. These tools do not send messages, make calls, edit DNS or change account billing.
